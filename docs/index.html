🪑 座る台の見分け方（タップで開く）

※アプリのリストは"当たりを付ける参考"。最終判断は目の前の台の今の数字（上の電卓）で。

① まず全台を見てから決める
・良さそうな1台目に即座らない
・候補を全部この電卓にかけて、推定設定が一番高い1台だけに予算を集中
② 残り予算で1000G回せないなら座らない
・47枚貸しなら1000G ≒ 1.5万円の余力が必要
・163G＝期待値はブレの28%／1000G＝69%／3000G＝120%
・短時間で良台を打つのは「+EV」ではなくギャンブル
③ 座っていい台
・マイジャグ/アイム → RB 1/250以下
・ゴーゴー/ミスター等 → 合算 1/128以下 かつ RB 1/290以下
・どちらも G2000以上（未満はブレるので信用しない）
④ 即・除外する罠
・差枚が大きくプラス(+1500超)なのに RB 1/300超 → BB上振れの偽物。座らない
・リストで上位でも、現地でRBが③を割ってたら外す
⑤ 穴場（群衆が見落とす本物）
・差枚は地味orマイナスなのに RB 1/250以下 の空き台 → 狙い目
⑥ 空いてなかったら
・本物が全部埋まってる → 打たない・帰るが正解。空いてる罠台に妥協しない
⑦ 座った後
・1000gごとに③の数字をキープしてるか再確認。割れたら即撤退
